# ADR 0001: リポジトリをAI共通コンテキストの正本にする

- Status: Proposed（このPRのレビュー・マージでAcceptedとする）
- Date: 2026-11-07

## Context
ChatGPT・Claude・ローカルLLMなどでは、会話履歴・メモリ・ファイルアクセスに差がある。設計意図がチャットにのみ存在すると、モデル切替時に重要な判断が失われる。

## Decision
人間とAIが読む共通指示を `AGENTS.md` に一本化する。目的・現状・データ契約・作業手順・引き継ぎ・ADRをリポジトリ内Markdownとして保存する。Claude/Copilot専用ファイルは参照だけとし、ルールを二重管理しない。

## Consequences
- モデルに依存せず、レビュー可能な差分として意思決定を追跡できる。
- 文書保守コストが発生するため、設計変更PRに関連文書の更新を要求する。
- AIの幻覚や古い説明を防ぐため、実際のコード/Excelとの照合は毎回必要。
