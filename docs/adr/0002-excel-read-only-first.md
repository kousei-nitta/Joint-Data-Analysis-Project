# ADR 0002: Excel原本を保持し、検証可能な分析から始める

- Status: Proposed（このPRのレビュー・マージでAcceptedとする）
- Date: 2026-11-07

## Context
現状はExcelを手入力しており、実データは完成していない。アプリUIや経済予測モデルを先行実装すると、不正データや誤解釈を見落としやすい。

## Decision
`product_prices.xlsx` を読み取り専用とし、最初の実装はメモリ内ダミーデータによる入力検証・価格変化率・グラフ出力に限定する。可視化や記事配信を可能にするが、数値計算はLLMに委ねない。実店舗/販路が未確認の情報は推論と明示する。

## Consequences
- 原本を壊さずにテスト・分析機能を先に作れる。
- 店舗別・条件別の比較にはデータ列を拡張する意思決定が別途必要。
- 景気指標としての妥当性は、実データの継続収集と後続の検証が必要。
