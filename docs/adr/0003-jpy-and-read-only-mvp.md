# ADR 0003: 初期価格は日本円・既存Excel読み取り専用で分析

- Status: Accepted（JPY方針は維持、Excel入力部分はADR 0004で置換予定）
- Date: 2026-11-07

## Context
入力担当者が `product_prices.xlsx` に商品ID・価格・日付を手入力している。作業完了を待たずに、同じテンプレートを使うダミーデータで分析の終端まで構築する必要がある。macOS・Windowsの共同開発で再現性が必要。

## Decision
- 現段階の価格列は**日本円**。他通貨や税込・税抜は混在させない（税区分は別途未決定）。
- 既存の2シート・列名を維持し、元ファイルは読み取り専用。商品の価格変化率とHTML/CSV/Streamlit表示を先に実装する。
- 同日・同商品IDの重複、0円、不正価格は黙って補正しない。初期バージョンでは入力エラー扱い。
- テストとCIはメモリ内の**明確に架空と表示されたExcel**だけを使う。

## Consequences
- 入力担当のpushを待たずに開発と検証を進められる。既存Excelの実物との型の違いは入力到着後に再確認する。
- 店舗別比較・為替分析は拡張列と追加の設計承認を要する。
- AIによる景気予測や因果評価の完成を意味しない。
