# プロジェクト概要（共有コンテキスト）

## 目的
中国の公式景気統計だけに依存せず、粉飾・集計上の制約を受けにくい可能性がある**民間の価格・取引行動データ**から、中国経済の変化を捉えるための補助指標を研究する。指標は仮説であり、実証前に予測可能性を主張しない。

## 最初の仮説
日本で中国向け転売・輸出に関係する買取業者の価格変化が、海外需要や流通事情の変化を反映し得る。川口・西川口周辺を候補地域として調べるが、「中国系」「中国人転売業者向け」の該当性は取引経路や店舗自身の公開資料等で裏付ける。候補地域・属性は未検証。

## 現段階のスコープ
- Excel（`product_prices.xlsx`）で記録した商品価格をPythonで読み取る。
- ダミーデータで入力検証・価格推移・簡単な変化率・グラフ出力を再現できる基盤を作る。
- 将来の実データ分析につなぐため、出典、品質、再現性、分析の限界を残す。
- 表示/UIとしてStreamlit＋Plotlyを想定するが、note等への記事出力も選択肢。**アプリ公開は目的そのものではない**。

## 初期スコープ外
- 中国景気の予測精度や因果関係の実証、投資助言、常時公開・課金・商用配信。
- 関係性を未検証の店舗を「中国向け転売業者が利用」と断定すること。
- 許諾のない大規模スクレイピング、第三者データの無断再配布。

## 成果判定（最初の分析MVP）
1. 同じExcel/ダミー入力から同じグラフ・数表を再生成できる。
2. 不正な日付、価格、商品IDを行単位で指摘できる。
3. 同一商品・同一条件の価格推移と前回比・期間変化率を計算できる。
4. 架空データと実測データ、参考買取価格と成約価格を明示的に区別する。
5. 2人と異なるAIがリポジトリ内文書だけを読んで作業を再開できる。

## チーム
2人（Pythonほぼ未経験の担当者＋開発経験者）、各週5〜10時間を想定。業務・分析仮説と技術実装を分担し、レビューで相互確認する。
