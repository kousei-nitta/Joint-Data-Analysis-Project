# Excel価格推移分析MVP仕様（実装PR・レビュー対象）

状態：`feat/excel-price-analysis-mvp` で実装中。ユーザーが承認して `main` にマージするまで**確定した完成機能ではない**。Excelの実データ入力は別担当で進行中。

## 狙い
Excelが未完成でも、同じシート・列を使った架空Excelをメモリ内で作り、**読み込み→検証→価格変動計算→Plotlyグラフ→CSV/HTML** の流れを端から端まで確認できる。

## 入力と検証

- Excelは「価格履歴」「商品マスタ」の2シート（詳細 `DATA_CONTRACT.md`）。20MB上限。
- エラーはシート名・Excel行番号・列名・修正すべき内容を表示し、不正な行を黙って除去しない。
- 元の `product_prices.xlsx`、アップロードされたワークブックの中身は変更しない。
- 明確に**架空データ**として表示した3商品・各5観測点のデモで動作可能にする。

## 分析と可視化

- 商品IDを選び、観測日の範囲を絞る。
- 前回観測からの価格差（円）、変化率（%）を計算。指定期間の最初/最後の観測価格と変化率を表示。
- 観測点を日付順に描画し、欠測日を埋めない。
- HTML形式のインタラクティブグラフとCSV分析結果をダウンロード可能。
- 2人のMac/Windowsの実行コマンドをそれぞれドキュメント化する。

## 非目標

中国景気の予測、異常検知AIの学習、複数店舗の差の推定、実際の買取業者との商流の裏付け、データ自動取得、インターネット公開、有料提供はこのPRに含めない。

## 自動テスト・受け入れ条件

- 全入力は架空Excelから生成。`100,000→90,000 = -10.0%` の期待値を単体テストで検証。
- 不正価格・不正日付・未登録ID・数値型ID・同日重複・空欄・不足シートを検出。
- エラー位置の行番号が実際のExcel行に対応。
- `uv run --locked pytest -q`、Ruff、既存環境チェック、デモ生成がCIで成功する。
- 実Excelの入力完了後は、別の承認ゲートで列/型の互換性を検証する。

反復検証とゲートは `LOOP_ENGINEERING.md` を参照。
