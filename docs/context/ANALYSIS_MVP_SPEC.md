# Google Sheets価格分析MVP（実装仕様）

## ゴール

2人がGoogleシートに同時編集し、Git pushをせずPythonで最新データを読み、商品ごとの価格推移・変化率・グラフ・CSV/HTMLを得る。分析ロジックは前PRを再利用する。入力は日本円。

## テスト可能な受け入れ条件

1. 架空データモードでネットワーク・認証なしでも3商品×5観測点のグラフ出力が可能。
2. シートの2タブを1回のbatchGetで取得。Google Sheets APIの**書き込みメソッドは一切呼ばない**。
3. 商品IDは文字列のまま保持（`001`と`1`の混同を防ぐ）。日付順に並べ、価格前回比と期間変化率を正しく計算。
4. 不正入力はタブ・Googleシート行番号・列名を表示。未登録ID、0円以下、不正日付、同日重複、型違反、空タブをテスト。
5. 401/403/404/429時の説明があり、429/一部5xxの再試行は最大2回。
6. `uv sync --locked`、`ruff check/format`、pytest、Googleアクセス不要のUIスモークとデモHTML/CSV生成がCIで成功。
7. macOS/Windowsの認証・実行手順が分かれている。シートID・秘密鍵・実データをGitに入れない。
8. 旧Excelバイナリをmain最新ツリーから削除（過去履歴には残る）。

## 非ゴール

- Googleシートへの自動書き込みやメンバー招待の自動化、Google Cloud課金の有効化。
- 店舗別価格・複数地域の検証、中国景気予測、外部向けWeb公開、note記事自動発行。
- 実際の非公開シートとの結合テスト（Google側設定は人間が行い、別の承認ゲートで実施）。
