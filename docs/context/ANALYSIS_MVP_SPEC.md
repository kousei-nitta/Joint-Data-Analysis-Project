# 次の実装PR向け：価格分析MVP仕様（Proposal）

この文書は**実装済み機能の説明ではない**。データがまだ揃っていなくても、架空データで分析処理を先に作るための提案と受け入れ条件。

## 入力
- `product_prices.xlsx` の「価格履歴」と「商品マスタ」（`DATA_CONTRACT.md` 参照）。
- CI/テストではopenpyxlでメモリ内に生成したダミーブックを使用し、実データを読み出して出力に含めない。
- ファイルの存在、20MBの暫定上限、シート名と列名の一致、各セルの型を検証する。

## 出力（数値の根拠を説明できること）
1. 検証結果：正常行数、エラー（シート名・Excel行番号・列名・修正ヒント）。
2. 商品ごとの日付順データ表（確認日・商品ID・商品名・価格）。
3. 前回比（円、%）と指定期間の始点終点比。欠損・0円・同日重複は適切に未計算扱い。
4. 折れ線グラフ（Plotly）およびHTMLエクスポート。生成物は`outputs/`へ。
5. 「架空/実測」の表示と集計条件。AI生成文章は初期MVPには必須としない。

## 作業の切り方（依存順）
- PR A：`io.py`、`validation.py`、正常/異常のExcel fixture＋pytest。
- PR B：`analysis.py`、期待値（100000→90000 = -10.0%）を使ったpytest。
- PR C：`charts.py`、任意のStreamlit表示、READMEに実行コマンド。
各PRを小さく保ち、将来のLLMや画面仕様と数値計算を分離する。

## Definition of Done
- 未登録ID、数値以外の価格、不正日付、欠損、同日重複の各テストがある。
- 順序が逆の入力でも時系列は日付順になる。
- Excel元ファイルのハッシュ/内容が実行前後で変わらない。
- lint、format、pytest、環境チェックを実行し、未実施項目があればPRに書く。
- 中国経済の先行性・因果性を主張しない。価格推移の分析だけを試作する。
