# 非公開Googleスプレッドシートの入力契約 v1（JPY）

データの正本は非公開Googleスプレッドシート。**GitHub上のExcelではない**。入力担当者にはシートの編集権限、分析用サービスアカウントには閲覧権限のみ付与する。

| タブ | 列見出し（1行目、左から順に） | 必須 | 形式 |
| --- | --- | --- | --- |
| 価格履歴 | 確認日 | Yes | 日付、ISO形式/ yyyy/mm/dd 推奨 |
| 価格履歴 | 商品ID | Yes | **テキスト**（例 `001`） |
| 価格履歴 | 価格 | Yes | 0より大きい数値、日本円（JPY） |
| 価格履歴 | 備考 | No | テキスト |
| 商品マスタ | 商品ID | Yes | 一意のテキストID（先頭ゼロ維持） |
| 商品マスタ | 商品名 | Yes | テキスト |

- APIは`values.batchGet`で`'価格履歴'!A:D`と`'商品マスタ'!A:B`を1回の**読み取り専用**リクエストで取得。`valueRenderOption=UNFORMATTED_VALUE`（通貨記号の混入を避ける）、`dateTimeRenderOption=FORMATTED_STRING`（表示された日付文字列）を指定。
- 日付の型、未登録商品ID、数値で入力されたID、価格の文字列化（例「10,000」）、0円以下、同一商品・同日の重複をエラーとする。
- 空行のみ無視し、欠落や誤値のある行は黙って消さない。エラーには**Googleシートのタブ名と行番号**を表示。
- ユーザーの編集からAPI応答まで更新差があり得る。Streamlitは最大5分キャッシュし、明示的な更新操作を用意。
- 店舗ID、商品状態、税区分、販売地域、為替、出典、成約/参考価格の別は**未定義**。同一商品と同じ日付に複数店舗分のデータを格納することはできない。これは次の仕様拡張ゲートで別途決める。
- 価格は当面JPY。中国景気との因果性・先行性を示すものではない。欠損日は補完しない。実データの取得・転用・商用利用条件は別途検証する。

## 以前のExcelとの互換性

見出しと2シートの構造は従来の`product_prices.xlsx`設計を踏襲。実際のGoogleシートへコピーする際は、商品ID列を**書式なしテキスト**に設定してから入力する。以前のExcelを再度Git追跡しない。
