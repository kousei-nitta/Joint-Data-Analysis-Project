# Excel入力仕様・価格分析データ契約（JPY v0.1）

ソースはリポジトリ直下 `product_prices.xlsx`。このファイルは**読み取り専用**で、分析プログラムが書き戻すことはない。既存 `docs/plan.md` が記述した列を対象とし、列追加やシート再構成は本PRでは行わない。実Excelへの入力が完了したら、この仕様と実体の照合を別PRで行う。

| シート | 列 | 型・意味 | 必須 |
| --- | --- | --- | --- |
| 価格履歴 | 確認日 | Excel日付・YYYY-MM-DD等の日付文字列 | Yes |
| 価格履歴 | 商品ID | **文字列**。例 `001`（先頭ゼロ維持） | Yes |
| 価格履歴 | 価格 | 0より大きい**数値セル、日本円（JPY）** | Yes |
| 価格履歴 | 備考 | 任意 | No |
| 商品マスタ | 商品ID | 文字列。一意 | Yes |
| 商品マスタ | 商品名 | 空でない文字列 | Yes |

## 運用ルールと検証

- 見出しは各シートの1行目。すべて空欄のデータ行は無視するが、一部だけ欠けた行はエラー。Excel上の行番号・列名を示す。
- 商品IDが文字列で保存されていない場合はエラー。Excelのセルの表示が `001` でも、数値 `1` として保存されていれば先頭ゼロが失われる恐れがある。文字列として入力する。
- 日付が不正、商品IDがマスタに存在しない、商品名が空、価格が数字でない・ゼロ・負数ならエラー。
- 同一商品IDの**同じ日**の価格が複数ある場合、エラー。平均や勝手な採用はしない（店舗列・時刻列がまだないため）。
- エラーがあるExcelは**部分集計をせず**、修正点を表示。元ファイルには変更を加えない。
- 価格は日本円として表示・出力する。税区分・新古状態・買取参考価格/成約価格は**未確定**であり現在のシートから区別できない。国外価格との比較・為替補正はこのデータ契約の対象外。
- グラフ・分析は実際に記録された日付のみ。欠測日の補完・架空の成約価格の生成はしない。

## 正規化後の列

`date`（日付）、`product_id`（文字列）、`product_name`（表示名）、`price_jpy`（数値）、`note`（任意）、`excel_row`（元行番号）。

分析では `previous_price_jpy`、`change_jpy`、`change_pct` を付与。例えば同じ商品IDが1月1日に100,000円、1月8日に90,000円なら `-10.00%`。観測1件なら変化率は算出不可。指定期間内の最初・最後の**観測値**を使う（期間の境界日に記録があるとは限らない）。

## 未決定・今後のデータ拡張

- 税込・税抜、状態/容量などの厳密な商品仕様、同日複数店舗の扱い。
- `shop_id`, `product_variant`, `condition`, `price_kind`, `source_url`, `observed_at`, `china_trade_evidence` 等の拡張。
- 価格取得・利用許諾・公開範囲。店舗属性と中国向け商流の関連は一次資料で裏付ける。

現行フォーマットでは**単一商品IDの時系列分析**までを保証する。店舗間差・中国景気との因果性や予測力の実証はできない。
